# Method

Read REQUEST.md and every named source document. Follow references between
messages before deciding how many distinct requests exist. A later explicit
correction replaces the earlier value; retain references to both messages.
Use `unknown` for an absent owner or date, and explain what the manager needs to
clarify. Never fill a blank by guessing.

Write the task's action table and RESULT.md under work/requests/<id>/. Include
source identifiers and distinguish extraction from execution. Check the output
against the supplied records. The starter's reference files are under inputs/
and its check is under tools/, outside the worker's write roots. Future tasks
may use other sources.
