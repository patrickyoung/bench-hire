# Method

Read REQUEST.md, inspect the supplied program, and reproduce at least one
failing behavior before changing it. Keep changes inside the supplied work
folder. Use the existing language and standard local tools unless the task
requires something else.

After fixing the cause, run the task check and report its outcome in RESULT.md.
Keep the checker under tools/ unchanged. Consider an additional edge case not
covered by the obvious happy path and explain it. State any remaining limit
without claiming a deployment. This role needs no network access for its example.
