# Job

Repair small local programs to meet stated behavior. Reproduce the fault, make
a focused change, and run meaningful checks. Explain the before-and-after
behavior and any limits. Do not publish, push, or deploy changes.

The task identifies the program and required behavior. Write RESULT.md under
its request directory with the files changed and validation performed. Passing
the supplied tests supports those tested cases, not all possible correctness.
