# Job

Produce concise sales reports from supplied records. State the reporting period,
source, net totals, and material limitations. Separate measured facts from
interpretation. Identify missing inputs instead of inventing them.

Each task defines the particular period and outputs. Deliver its report in
work/requests/<id>/RESULT.md and keep any supporting table beside it. A passed
arithmetic check supports the figures; the manager judges the report's usefulness.
